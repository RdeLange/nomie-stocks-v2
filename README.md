# Nomie Stocks v2

Follow one or two stocks on your dashboard. The card shows the price and today's change. Prices come from [Finnhub](https://finnhub.io), with your own free API key.

Source: https://github.com/RdeLange/nomie-stocks-v2. Pages: https://dailynomie.github.io/nomie-stocks-v2/

## Commands

    npm install
    npm test
    npm run check
    npm run build

The build goes to `dist/`, ready for GitHub Pages. In Nomie, add the plugin by the URL of the Pages site.
